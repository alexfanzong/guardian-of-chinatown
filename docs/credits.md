# Asset and dependency notes

Alex Fan led the game's design, gameplay architecture and art direction. AI tools assisted with code and original artwork. The street, fighters, victory pose and cover were generated for this project from the author's visual direction. The tea and elixir icons are original SVG code. Sound effects are synthesized locally by the game.

The same [source-available license](../LICENSE) covers the original artwork. Commercial use and publishing modified artwork require separate written permission.

The 2.0 opening uses four cuts from one original comic page. Its English balloons, impact lettering and masthead come from that page. Clean backgrounds fill the spaces behind the moving ink. Eight additional drawings animate the monster emerging and the heroine landing. The combat atlas adds new poses for the same characters.

The opening soundtrack combines original synthesized weather, footsteps, glass, cloth and percussion with one locally synthesized line for the heroine. The mixed audio ships inside the game.

The Chinese interface uses a locally bundled subset of TakWolf's Fusion Pixel 12px Simplified Chinese font. Its upstream licenses and credits accompany the web build and the offline game. [Font notices](../public/CHINESE-FONT-NOTICE.txt)

The game runs on React. The static build includes the game's license in `LICENSE.txt` and the bundled JavaScript dependencies' licenses in `THIRD-PARTY-NOTICES.txt`.

Guardian of Chinatown is an independently created browser game.
